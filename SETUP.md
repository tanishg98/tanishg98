> The README at `tanishg98/tanishg98` is a special GitHub repo. Whatever's in its README.md renders at the top of your profile page (`github.com/tanishg98`).

## Step 1 — create the special repo

On GitHub, click **New repository** (or `gh repo create`):

- **Repository name:** `tanishg98` (must match your username exactly — that's the magic)
- **Description:** `Profile README · what I'm building`
- **Public**
- **Don't initialize** with README/license/.gitignore (we already have one)

GitHub will show a "✨ You found a secret!" banner — that's the confirmation it'll be used as your profile.

## Step 2 — push this folder

```bash
cd ~/projects/tanishg98-profile
git remote add origin https://github.com/tanishg98/tanishg98.git
git branch -M main
git push -u origin main
```

## Step 3 — verify

Visit `https://github.com/tanishg98`. The README from this folder should render at the top, above your repos.

## Step 4 — wait for the snake animation

The animated snake graph is generated by a GitHub Action (`.github/workflows/snake.yml`). On first push it runs automatically, takes ~2 minutes, then commits the snake SVG to the `output` branch. Until then the snake image will 404. After the first run, it refreshes every 12 hours.

To trigger it manually after pushing:

```bash
gh workflow run "Generate snake animation"
```

Or visit the **Actions** tab on the repo and click "Run workflow."
