## 🛠️ Tanker

<div align="center">

[![Tanker](https://img.shields.io/badge/🛠️%20Tanker-View%20Repo-%23CC785C?style=for-the-badge&logo=github&logoColor=white)](https://github.com/tanishg98/tanker)
[![Status](https://img.shields.io/badge/Status-ACTIVE-22C55E?style=for-the-badge)]()
[![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)](https://github.com/tanishg98/tanker/blob/main/LICENSE)
[![Built with Claude Code](https://img.shields.io/badge/Built_with-Claude_Code-CC785C?style=for-the-badge)](https://docs.claude.com/claude-code)

</div>

**A Claude Code framework that ships deployed products from a one-line brief.**

```bash
$ /cto "AI business analyst for Indian D2C sellers — chat with your data"

▸ intake → context → reference → grill → benchmark → prd
✋ GATE 1 — PRD ready for review (12 min)  →  approved
▸ architect → plan → advisor → provision (gh + supabase + vercel + railway)
▸ build (parallel: frontend + backend + data + content)
✋ GATE 2 — MVP ready for review (14 min)  →  approved
▸ deploy → smoke test → monitor

✓ Production live: https://indian-d2c-analyst.vercel.app
  cost: $5.42 / $10  ·  total: 2h 47m  ·  human attention: 26m
```

**What's different:** Two human gates pre-qualified by review agents · real infrastructure provisioning · resumable across sessions · cost ceiling built in · local semantic retrieval over your knowledge corpus · opinionated quality rails (No AI Slop).

**What it ships:** 34 skills · 9 agents · 3 always-on rules · JSON sidecar contracts · `/cto` autopilot · honest comparisons vs MetaGPT, AutoGen, CrewAI, Aider.

## 📸 Persona Studio

<div align="center">

[![Persona Studio](https://img.shields.io/badge/📸%20Persona%20Studio-Live%20Demo-%23CC785C?style=for-the-badge&logo=vercel&logoColor=white)](https://persona-studio-lime.vercel.app)
[![Status](https://img.shields.io/badge/Status-PRIVATE_BETA-FFAA00?style=for-the-badge)]()
[![Built with](https://img.shields.io/badge/Built_with-Tanker_/cto-CC785C?style=for-the-badge)]()

</div>

**India-first AI influencer studio.** Build one believable virtual creator, lock her identity across scenes, generate reusable content for Indian campaigns. One `/cto` brief. One weekend. Deployed.

> Persona Studio is the proof Tanker works end-to-end. From brief to live URL with auth, identity-lock model, scene generator, and feed preview — about 30 minutes of total review time across two human gates.

**Key features:** Identity lock with reference-image consistency · India-first creator presets (Bandra cafe, Bengaluru office, monsoon streetwear, Diwali studio) · 4:5 Instagram preset · Editorial-realism scene generator · Tap-first builder

**Live:** [persona-studio-lime.vercel.app](https://persona-studio-lime.vercel.app)
